# Как устроен процесс Entryx

Установка — в [README](../README.md). Здесь — как работает процесс, мост и агенты.

Первая рабочая сборка по карте процессов ENTRYX v4 (24.11.2026).

```
Twenty CRM (сделка, этап, флаги, задачи)
      │ этап сменился / задача закрыта          (вебхук или опрос раз в 10 с)
      ▼
bridge/ — движок: этап → волны задач по ролям → переход дальше
      │ для каждой роли в открывшейся волне
      ▼
Dify — агент роли (workflow): черновик задачи, письма, что проверить
      │
      ▼
Задача в Twenty «[Юлия] 1 · …», назначена человеку. Закрыл задачу = подтвердил.
Все блокирующие задачи этапа закрыты → мост переводит сделку на следующий этап.
```

Агенты друг с другом не общаются. Их связывает этап сделки в CRM.

## Что где

| Путь | Что это |
|---|---|
| `process/stages.yaml` | Процесс: роли, агенты, флаги, 13 этапов воронки, шаги каждой роли по волнам. Единственный источник. |
| `tools/gen_dify_apps.py` | Собирает из процесса 7 агентов Dify в `dify-apps/*.yml`. |
| `dify-apps/` | DSL агентов для импорта в Dify: закупка, менеджер, логистика, финансы, приёмка, монтаж, руководитель. |
| `bridge/` | Мост: `app.py` (API и опрос), `engine.py` (движок), `twenty.py` (клиент CRM), `setup_crm.py` (настройка воронки и полей). |
| `crm/` | Docker Compose для Twenty v2.57.1. |

Dify запускается из папки `dify/` (`docker compose up -d`), открывается на http://localhost.
Twenty — `crm/` (`docker compose up -d`), открывается на http://localhost:3000.

## Доступы (локальные, тестовые)

Логины и пароли администратора Dify и Twenty: `.secrets/local-accounts.env` (не коммитится).
Ключ Twenty и ключи 7 агентов Dify для моста: `bridge/.env`.
`tools/dify_setup.py` сам входит в Dify, ставит плагин Gemini, импортирует и публикует агентов и пишет их ключи в `bridge/.env`.
Ключ модели вводит человек: Dify → аватар → Настройки → Поставщик моделей → Gemini (ключ Google AI Studio).

Агенты в чате берут живые сделки и задачи у моста (`GET /context?agent=…`). Для этого в `dify/.env` разрешён один внутренний адрес:
`SSRF_PROXY_ALLOW_PRIVATE_DOMAINS=host.docker.internal`. Остальные внутренние адреса прокси Dify по-прежнему блокирует.
Мост должен быть запущен, иначе агент отвечает по процессу и пишет, что CRM недоступна.

## Трекер проектов

http://localhost:8787/ — доска по 7 фазам (Договор → Закрытие): на ком каждая сделка, что дальше, что стоит или просрочено, история шагов. Фазы задаются в `process/stages.yaml` (`phases`). Обновляется каждые 5 секунд.

## Как запустить с нуля

1. **Twenty.** Открыть http://localhost:3000, создать аккаунт и рабочее пространство.
   Settings → APIs & Webhooks → создать API key. Скопировать `bridge/.env.example` в `bridge/.env`, вставить ключ в `TWENTY_API_KEY`.
2. **Воронка и поля:** `cd bridge` → `..\.venv\Scripts\python setup_crm.py`.
3. **Мост:** `cd bridge` → `docker compose up -d --build`. Работает в Docker без открытой сессии и перезапускается сам. Где сделки и на ком они: http://localhost:8787/status
   Без ключей Dify мост уже работает: задачи создаются по шаблонам из `stages.yaml`. Это ручная версия.
4. **Dify.** http://localhost/install → аккаунт администратора. Plugins → Gemini, ключ Google AI Studio.
   Studio → Import DSL file → по очереди `dify-apps/*.yml` → Publish. У каждого: API Access → API Key → в `bridge/.env` (`DIFY_KEY_ZAKUPKA` и т. д.). Перезапустить мост.
5. **Проверка:** в Twenty создать сделку на этапе «Договор с заказчиком». Через ≤10 с у менеджера появится задача. Закрыть её — сделка уйдёт в «Сверку», появится задача Юлии.

Модель в агентах — `gemini-flash-latest` у провайдера `langgenius/gemini/google`. Другая модель:
`.venv\Scripts\python tools\gen_dify_apps.py --provider <провайдер> --model <модель>` и импорт заново.

## Как менять процесс

Правится только `process/stages.yaml`: шаг, правило, срок, флаг `when`, порядок волн.
После правки: перезапустить мост; если поменялись шаги или правила — пересобрать агентов и импортировать их заново.

## Чего пока нет

- Эскалации и напоминания по срокам (3 дня аванс, 2 недели без движения, 5 дней молчания завода) — нужен планировщик.
- Петли: возврат этапа назад сейчас делается вручную, мост просто откроет задачи этапа заново.
- Несколько фур, письма и WhatsApp наружу, разбор входящих (S4), проверка документов (S1), сверка (S2).
- Отдельные пользователи на каждую роль: пока все задачи назначаются одному участнику, роль видна в названии задачи.

## Варианты ответа, проблемные ветки, уведомления

- У шага в `process/stages.yaml` может быть `opts: <набор>`: в чате вместо одной «Подтвердить» появляются кнопки вариантов из `option_sets`.
  Вариант может поставить флаг в сделке (`set`), попросить причину (`reason`), открыть задачу проблемной ветки (`then` → `branches`)
  или перевести сделку в «Отложена» / «Отменена» (`stage`). Причина уходит в задачу следующего и в журнал сделки.
- «Готово» текстом закрывает задачу, если у человека одно дело (или одно держит переход); у задачи с вариантами бот спросит, как прошло.
- Под каждым ответом агента в чате — «Ваши дела сейчас» с кнопками: поговорили с агентом и сразу передали карточку дальше.
- Ответ на задачу сразу говорит, кому уходит карточка или кого ещё ждём.
- Уведомления роли: http://localhost:8787/inbox?agent=<агент> (ссылка «🔔 Уведомления» в чате). Просрочено, срок сегодня,
  напоминание за день, эскалации Опердиру (просрочка от 1 дня и стоящие сделки), проблемы по сделкам, новые задачи.
  Правила — секция `escalation` в `stages.yaml`.

## Веб-чат с агентами (http://localhost:8787/app)

Страница чата в дизайне прототипа: та же логика (агенты Dify + мост), другой фронт.
- Роль выбирается в шапке (`?agent=manager`, `rukovoditel`, …), разговор продолжается с того места, где остановились; «+» — новый разговор.
- Ответ агента идёт потоком. Дела из «Что на мне сегодня» — карточками с кнопками вариантов.
- Внизу всегда кнопки «Что на мне сегодня», «Мои проекты» и «Уведомления» с числом важных; уведомления открываются там же, поверх чата.
- Ключи агентов остаются в `bridge/.env`: страница ходит в Dify через мост (`/api/chat`, `/api/history`).
- `bridge/static` подключён томом: правка страниц не требует пересборки контейнера.
- Переходы: ссылка «🔔 Уведомления» в чатах Dify ведёт на `/app?agent=…#inbox` (чат с открытыми уведомлениями). На `/inbox` каждое уведомление — ссылка в чат роли (`/app?agent=…&ask=Сегодня` для своих задач, `ask=Мои проекты` для проблем и эскалаций), сверху кнопка «← В чат».
